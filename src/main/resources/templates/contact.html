Frequently Asked Questions

How do I create an event? ⌄
Log in with an Organizer or Admin account, then click "+ New Event" in the navigation bar. Fill in the event details and submit the form.
How do I get an Organizer role? ⌄
Register a new account and contact an Admin to have your role updated to Organizer through the Admin panel.
Why can't I access the Admin panel? ⌄
The Admin panel is restricted to users with the ADMIN role. If you need access, contact the system administrator.
Can I filter events by type? ⌄
Yes. On the Events page, use the filter dropdown to select a specific event type, then click Apply to update the results.
How are passwords stored? ⌄
All passwords are hashed using BCrypt before being stored in the database. Plain text passwords are never saved.
