The Project

EventBook is a web app where users can find and manage events like workshops, meetups, and conferences.

This is the final project for CPAN-228 at Humber College, made by Group 2. Users can sign in, browse events, and do different things depending on their role.

Key Features

01
Secure Login
Users register and log in with a password. Passwords are not saved as plain text.
02
User Roles
There are three roles: Admin, Organizer, and User. Each role can do different things on the site.
03
Event Management
Users can create and browse events. You can filter by type and sort by date, price, or capacity.
04
Admin Panel
Admins can see all users, change their roles, disable accounts, or delete them.
